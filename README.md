
# 🏠 House Price Prediction

A Machine Learning regression project that predicts median house values using housing characteristics from the California Housing dataset. The project explores housing data, performs data preprocessing, trains and evaluates regression models, and deploys the selected model through an interactive Streamlit web application.

## 🎯 Project Objectives

- Explore and understand the California Housing dataset.
- Perform exploratory data analysis and examine feature correlations.
- Prepare and scale the dataset for machine learning.
- Train and evaluate Linear Regression and Random Forest Regression models.
- Compare model performance using MAE, MSE, RMSE, and R².
- Deploy the best-performing model through Streamlit.

## 📊 Dataset

**Dataset:** California Housing Dataset

**Source:** Scikit-learn

- Total records: 20,640
- Input features: 8
- Target variable: `MedHouseVal`

The dataset contains information about housing districts in California, including median income, house age, average rooms, population, occupancy, latitude, and longitude.

## 🤖 Models Developed

Two regression algorithms were trained and evaluated:

1. Linear Regression
2. Random Forest Regressor

### Model Performance

| Evaluation Metric | Linear Regression | Random Forest |
|---|---:|---:|
| MAE | 0.5332 | 0.3277 |
| MSE | 0.5559 | 0.2560 |
| RMSE | 0.7456 | 0.5060 |
| R² Score | 0.5758 | 0.8040 |

**Selected Model:** Random Forest Regressor

Random Forest achieved better performance across all four evaluation metrics and was selected for deployment.

## 🚀 Streamlit Application

The application allows users to enter housing characteristics and receive an estimated median house value generated by the trained model.

The prediction is displayed in US dollars.

**Note:** The model predicts district-level median house values, not the market value of an individual property.

## ⚙️ Installation and Usage

Clone the repository:

```bash
git clone https://github.com/Dheraa/House-Price-Prediction.git
```

Navigate into the project directory:

```bash
cd House-Price-Prediction
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run streamlit_app.py
```

## 📈 Evaluation

The Random Forest Regressor achieved an R² score of 0.8040, indicating that it explained approximately 80.4% of the variance in the test dataset.

Its lower MAE and RMSE compared with Linear Regression also indicate better prediction accuracy on the test data.
